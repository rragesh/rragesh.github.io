# Project copy sources

The owner requested accessible, engaging copy across all nine project pages. The rewrite uses the original project data (now `src/data/projects.json`), existing project photographs, and the sources below. Historical project URLs, publications, repositories, and demonstration IDs are preserved.

## Content boundaries

- `recharge`: the original description states development and successful simulation in Gazebo. The new copy describes a simulated return-to-charge workflow, not a measured physical-fleet deployment.
- `localization`: the original description supplies four cameras, overlapping coverage, a roughly one-metre-square mounting arrangement, CAN/ROS/RViz integration, LED calibration boards, and approximately 5 cm accuracy after calibration. The result is tied to the experimental setup rather than generalized to every environment.
- `Saksha`: the original description supplies the linked arms, joint-position sensing, Arduino/servo control, 25-millisecond mapping cycle, and teach/record/playback modes. The copy explains these concepts without new performance claims.
- `astra`: the original description supports ground/aerial coordination, observation, sensor integration, ROS, a central computer, and close-range tests in a low-interference wireless environment. The rewrite stays at a high-level prototype description. Unsupported population statistics and universal deployment claims from the old copy are not repeated.
- `dhruv`: the original description and photograph support a hazard-inspection rover with gas sensors, thermal/infrared imaging, ultrasonic sensing, remote telemetry, and a five-degree-of-freedom arm. No new rescue outcomes, certification claims, lifting limits, or field-range guarantees are added.
- `phoenix`: the original page establishes Phoenix II, the 2016 UK rover challenge, and Ragesh’s team-lead role. The owner’s CV/source notes support the 15-person multidisciplinary team and navigation/manipulation work. No competition rank or reliability metric is invented.
- `phoenix_dummy`: the original page establishes Phoenix I, the 2016 University Rover Challenge in Utah, and Ragesh’s team-lead role. The rewrite does not transfer unverified specifications or the Phoenix II team size to this rover.
- `8_leg` and `8_leg_dummy`: the existing published papers were read. Both identify Ragesh as a co-author and document the rover’s adjustable wheel supports, system design, prototype construction/testing, and passage through the 2015 University Rover Challenge Critical Design Review. The owner’s history supports his system-integration contribution. The pages distinguish design explanation from field-trial material rather than duplicating the same text. No NASA-performance comparison or extrapolated operational capability is added.
